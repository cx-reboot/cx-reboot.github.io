本地文件包含（LFI）

在下面的案例研究中，我们将尝试将可执行代码写入/var/log/apache2/目录中的Apache的access.log文件。我们首先需要检查哪些信息是由我们控制并由 Apache 保存在相关日志中的。在这种情况下，“受控”意味着我们可以在将信息发送到 Web 应用程序之前对其进行修改。我们可以阅读 Apache Web 服务器文档或通过 LFI 显示该文件
