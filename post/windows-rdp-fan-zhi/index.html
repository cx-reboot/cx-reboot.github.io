CVE-2020-0655

CVE-2020-0655 是 CVE-2019-0887补丁引发新漏洞
漏洞产生原因
在基于Unix的系统中，使用的路径分割字符是/，而在Windows系统中使用的是分割字符为\但Windows最早是支持/和\的。因此，执行任何文件操作都会遇到这两个分隔符。研究人员发现的漏洞是一个检查的实现漏洞。许多核心Windows功能的开发人员可能忘记了Windows系统也支持/字符，所以会重新实现只支持\的文件路径逻辑。
